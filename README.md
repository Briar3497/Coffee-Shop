# 🐉☕ The Sleeping Dragon Cafe

Welcome to the official repository for **The Sleeping Dragon Cafe**, a fantasy-themed book café where magic meets caffeine. This project demonstrates a **full-stack web application** featuring an **Angular front end**, a **Spring Boot REST API back end**, and a **relational database** for managing café content and customer data. It serves as the digital home for our sanctuary, giving adventurers everything they need to plan their next quest—or simply enjoy a quiet afternoon with a good book.

# ✨ About the Project

**The Sleeping Dragon Cafe** is more than just a coffee shop—it is a portal to another realm.

The application allows visitors to browse handcrafted drinks and pastries, explore upcoming events, view café information, and experience an immersive fantasy-themed interface.

This project was built to demonstrate modern full-stack web development by combining a responsive Angular user interface with a Java Spring Boot REST API and a relational database.

---

# 🛠️ Features

## ☕ Café Menu

Browse a curated selection of handcrafted beverages and treats:

* **Alchemist's Brews** – Specialty lattes and handcrafted coffee creations
* **Elven Teas** – Rare herbal infusions and calming blends
* **Dwarven Delights** – Hearty pastries and savory snacks

* Weekly Dungeons & Dragons campaigns
* Author signings

* Interactive location information

# 💻 Technology Stack

### Front End

* Angular
* TypeScript
* HTML5
* CSS3
* Bootstrap

### Back End

* Java
* Spring Boot
* Spring Data JPA
* RESTful API

### Database

* MySQL (or your configured relational database)
* Hibernate / JPA

---

# 🏗️ Architecture

The application follows a three-tier architecture:

```
Angular Front End
        │
        ▼
Spring Boot REST API
        │
        ▼
Relational Database
```

The Angular client communicates with the Spring Boot back end through REST API endpoints. The back end processes business logic, interacts with the database using Spring Data JPA and Hibernate, and returns JSON responses to the front end for display.


Navigate to the project directory:

```bash
cd Coffee-Shop
```
